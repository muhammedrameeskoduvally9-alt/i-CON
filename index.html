Google Sheet Live Sync Setup (സൗജന്യ ക്ലൗഡ് കണക്ഷൻ)

എല്ലാ കുട്ടികളുടെയും ഫോണിൽ ഒരേ സമയം ചോദ്യങ്ങൾ വരാനും മാർക്കുകൾ ഒരൊറ്റ Google Sheet-ൽ സേവ് ആവാനും താഴെ പറയുന്ന 4 സ്റ്റെപ്പുകൾ ചെയ്യുക:

  1. 1
    പുതിയ Google Sheet തുടങ്ങുക: sheets.new തുറന്ന് "Dars Newspaper Quiz" എന്ന് പേര് നൽകുക. മുകളിലെ മെനുവിൽ Extensions > Apps Script ക്ലിക്ക് ചെയ്യുക.
  2. 2
    Apps Script കോഡ് പേസ്റ്റ് ചെയ്യുക: അവിടെയുള്ള പഴയ കോഡ് മായ്ച്ചുകളഞ്ഞ് താഴെയുള്ള ബട്ടൺ അമർത്തി കോപ്പി ചെയ്ത കോഡ് പേസ്റ്റ് ചെയ്ത് സേവ് (Ctrl+S) ചെയ്യുക.
  3. 3
    Deploy ചെയ്യുക: മുകളിൽ വലതുവശത്ത് Deploy > New deployment ക്ലിക്ക് ചെയ്യുക. Type ആയി Web app തിരഞ്ഞെടുക്കുക. Who has access എന്നത് "Anyone" എന്നാക്കി Deploy അമർത്തുക. (Authorize access ചോദിച്ചാൽ Allow കൊടുക്കുക).
  4. 4
    Web App URL താഴെ പേസ്റ്റ് ചെയ്യുക: ലഭിക്കുന്ന https://script.google.com/macros/s/.../exec ലിങ്ക് കോപ്പി ചെയ്ത് താഴെ പേസ്റ്റ് ചെയ്ത് Save & Connect അമർത്തുക.
